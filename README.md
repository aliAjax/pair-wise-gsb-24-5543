# hxwl-10 考古探方记录

遗址探方、地层关系与出土物坐标的可续作现场记录。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能

- **断网登记带原版本**：离线改动写入本机副本并进入待同步清单，每条改动记录所基于的版本（baseRev）。
- **回连按字段合并**：以同步基线做逐字段三路合并；仅一侧改动直接采用，不再整记录覆盖。
- **同字段冲突保留两版**：双方改了同一字段时，本机版与对方版都保留在「待确认」页，人工确认一版后写入双方，另一版留存日志。
- **依赖失效与重算**：地层关系、层位、探方原点或坐标基准任一变更，依赖它的遗迹/出土物坐标即失效并排入重算；深度可由叠压关系推导，关系缺失或成环会导致重算失败。
- **可续作**：重算失败保留坐标草稿与待办，持久化到 localStorage，下次打开自动继续；补齐层位深度或地层关系后自动重算成功。
- **清单与摘要**：每条记录标明当前版本、待同步/待确认状态；摘要区标明当前版本（本机/对方/合并轮次）、待确认项与失效范围。

## 演示流程

1. 「模拟断网」→「断网登记（H12 复测＋陶纺轮）」
2. 「补录地层关系 L104」「改动 H12 层位/坐标」「调整坐标基准」（模拟领队端）
3. 「回连并按字段合并」：H12 的 N 坐标与备注保留两版待确认；地层关系与坐标基准变更使依赖坐标失效；L104 深度未闭合导致 H12/A001/陶纺轮重算待办
4. 在「地层」页补齐 L104 深度（如 1.20–1.60 m），待办自动清掉；在「待确认」页选择保留哪一版
