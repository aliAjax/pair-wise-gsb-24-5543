# hxwl-10 考古探方记录 · 可续作的现场记录

遗址探方、地层关系、遗迹单位与出土物坐标的**离线优先**档案：
断网可继续登记，回连后按字段合并，冲突两版保留，依赖坐标自动级联失效与重算。

## 技术栈

React 19 + Vite + TypeScript + CSS，纯前端实现；
本地档案持久化在 `localStorage`，用一个「服务端影子库 + 发件箱」在浏览器内模拟对端与回连同步，无需后端即可演示完整流程。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 解决的现场问题

记录员断网登记，回连后两边都改过记录——**后到的坐标不再无声盖掉对方补录的地层关系**：

1. **离线改动带原版本**
   - 断网期间每次登记只升 `version`，`baseVersion` 锁定原版本，字段原值存入发件箱；
   - 离线新建的探方/地层/遗迹/出土物标记为「本机草稿·待上传」。
2. **回连按字段合并，同字段冲突保留两版**（`src/sync.ts`，三方合并）
   - 只有一方改 → 取改动方；两边改不同字段 → 自动合并；
   - 同字段两边都改且不一致 → 字段进入待确认，原版本/本机版/对端版三版并列，记录员逐条「采用此版」，确认前该字段锁定不参与重算。
3. **地层关系/坐标基准变更 → 依赖项级联失效并等待重算**（`src/model.ts`）
   - 坐标基准（基准点名、E/N、高程）一变：同探方地层高程链、全部遗迹与出土物坐标失效；
   - 层序、层厚、地层关系一变：同探方地层高程链、开口遗迹及其出土物坐标失效；
   - 遗迹开口深度/相对坐标一变：其出土物坐标失效。失效记录带原因和触发版本。
4. **重算失败保留草稿和待办，下次打开继续**
   - 上游缺失、关键输入有未确认冲突等情况下重算失败：录入草稿原样保留，失败原因进入「重算待办」，并持久化；
   - 再次打开档案或点击「立即继续重算」时自动重试；上游就绪后下游逐层恢复。
5. **清单和摘要标明当前版本、待确认项与失效范围**
   - 每张记录卡显示当前 `v版本`、离线原版本、草稿/冲突/失效徽章与失效原因；
   - 顶部四块概览（档案规模/待确认/失效范围/重算待办）+ 三个汇总面板；
   - 「导出摘要」生成 Markdown：当前版本、三版冲突对照、失效范围与原因、各实体清单。

## 重算口径（依赖链：探方 → 地层 → 遗迹 → 出土物）

- 地层：层顶高程 = 基准高程 − 上方各层层厚之和；层底 = 层顶 − 本层厚。
- 遗迹：绝对 E/N = 基准 E/N + 相对偏移；开口高程 = 所属层顶高程 − 开口深度。
- 出土物：绝对 E/N = 所属遗迹绝对坐标 + 相对偏移（直接出土于地层时以基准点为原点）；绝对高程 = 基准高程 − 出土深度。
- 按 地层 → 遗迹 → 出土物 的顺序多轮重算，保证上游本轮算好后下游可跟进。

## 操作引导

1. 打开即是含 2 个探方、3 条地层、2 处遗迹、3 件出土物的示例档案，坐标已算好；
2. 点「布置离线分歧示例」：自动断网，本机改第3层关系（→平行）与陶片12坐标，同时模拟对端把关系改向（→打破）、补录填土、坐标另录一版；
3. 点「回连同步」：观察 `soilColor` 自动合并，`relation`、`relX` 同字段两版保留待确认，依赖坐标失效；
4. 在冲突面板逐条采用版本，级联坐标自动重算；也可「模拟断网」后自行在卡片里编辑再回连；
5. 制造失败：清空某探方基准高程并保存，可看到下游进入重算待办；填回后点「立即继续重算」或刷新页面即可恢复；
6. 「导出摘要」下载 Markdown 清单；「重置示例」清空本地存档回到初始档案。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 版本化实体、字段冲突、失效标记、发件箱、重算待办等类型 |
| `src/model.ts` | 字段定义、依赖链、级联失效、坐标/高程重算 |
| `src/sync.ts` | 回连三方合并：按字段自动合并 + 同字段双版冲突 |
| `src/seed.ts` | 初始示例档案 |
| `src/store.tsx` | 状态管理、断网发件箱、重算待办、localStorage 持久化、全部动作 |
| `src/summary.ts` | 当前版本/待确认/失效范围统计与 Markdown 摘要导出 |
| `src/ui/components.tsx` | 徽章、实体卡片、三版冲突面板、编辑/新增弹窗 |
| `src/App.tsx` | 清单、筛选、概览面板、日志与操作入口 |
